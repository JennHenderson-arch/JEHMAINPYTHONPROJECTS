Set pytest (custom) tags, like smoke, regression, etc. - see pytest,inin and how these are currently set up in smoke tests.
These can be set in playwright yaml file for GitHub Actions - and run individually: 
pytest -m smoke
pytest -m "not smoke"
pytest -m "smoke or api"


Running jobs via playwright.yaml
on:
  schedule:
    - cron: "0 9 * * *"   # 4 AM EST

jobs:
  nightly-smoke:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run smoke tests
        run: pytest -m smoke --tracing=on
